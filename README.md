# WalkCharger
⚡ Energy Harvesting Shoes – My First ECE Mini Project💡
Welcome to my first self-built mini project in the field of Electronics and Communication Engineering (ECE) – an innovative pair of electricity-generating shoes! 👟🔋

💡 Project Description : 
This project demonstrates a simple wearable device that generates electricity from footsteps using piezoelectric discs. The harvested energy is rectified, stored in a rechargeable battery, and can be used to charge small devices via USB.

🎯 Key Features
-Piezoelectric discs to harvest kinetic energy
-Bridge rectifier using 1N4007 diodes
-Capacitor for voltage smoothing
-Rechargeable battery for energy storage
-USB charging output for small gadgets
-TP4056 charging module with overcharge protection
-Compact circuit mounted on an FR4 fiberglass base

🛠️ Components Used
*Piezoelectric discs
*Diodes (1N4007)
*Electrolytic Capacitor (470μF, 25V)
*TP4056 Li-ion charging module
*Lithium-ion 3.7V rechargeable battery
*USB Type-A female charging port
*FR4 PCB sheet fiberglass
*LED indicators, jumper wires.

🚀 Why I Built This
As an ECE student, I wanted to explore energy harvesting and wearable tech in a practical, hands-on way. This project reflects my passion for innovation, electronics, and sustainable solutions.
